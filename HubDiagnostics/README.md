# Hub Diagnostics is now Hub Inspector

The app was renamed and moved to [HubInspector](../HubInspector/README.md). Install it from there.

`HubDiagnostics.groovy` in this folder is the current Hub Inspector code. It stays at this address only so an install that still imports from the old URL keeps receiving updates. Importing it once switches the app to the new location; your settings, history and dashboard link carry over.

This folder will be removed in a later release.
